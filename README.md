☕ 01. About The Project

Welcome to Dirty Cafe Sales Analysis — a practical data analytics project focused on transforming a messy real-world cafe transaction dataset into clean, structured, analysis-ready information.

Real-world datasets are rarely perfect.

This dataset contains challenges such as:

❌ Missing values
❌ Duplicate records
❌ Invalid entries
❌ Incorrect data types
❌ Inconsistent formatting
❌ Structural anomalies
❌ Incomplete transaction information

Using Python, Pandas, Jupyter Notebook, and OpenPyXL, the raw dataset is systematically inspected, cleaned, transformed, analysed, and finally converted into useful business insights.

☕ Core Mission

Transform chaotic cafe transaction records into clean data, meaningful analytics, and decision-ready business intelligence.

🧹 07. Data Cleaning Process

The project follows a structured cleaning strategy instead of blindly deleting problematic records.

🔍 Step 1 — Inspect The Dataset

df.head()
df.shape
df.info()
df.isnull().sum()
df.duplicated().sum()

This helps identify:

* Dataset dimensions
* Column names
* Data types
* Missing information
* Duplicate transactions
* Potential inconsistencies

⸻

🧼 Step 2 — Handle Missing & Invalid Values

The dataset is checked for problematic entries such as:

NaN
UNKNOWN
ERROR
Invalid numerical values
Missing transaction information

Each column is handled according to its meaning instead of applying a single cleaning strategy everywhere.

⸻

🔄 Step 3 — Correct Data Types

Columns are converted into appropriate formats.

df["Quantity"] = pd.to_numeric(df["Quantity"], errors="coerce")
df["Price Per Unit"] = pd.to_numeric(df["Price Per Unit"], errors="coerce")
df["Total Spent"] = pd.to_numeric(df["Total Spent"], errors="coerce")
df["Transaction Date"] = pd.to_datetime(
    df["Transaction Date"],
    errors="coerce"
)

⸻

🧮 Step 4 — Validate Revenue

Where sufficient information exists:

Total Spent = Quantity × Price Per Unit

This allows transaction values to be validated or reconstructed when appropriate.
