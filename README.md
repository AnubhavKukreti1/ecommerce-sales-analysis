# ☕ Dirty Cafe Sales Data Analysis using Pandas

This project is about cleaning, analyzing and understanding a messy cafe sales dataset using Python and Pandas.

The dataset contains different types of problems like missing values, duplicate records, incorrect values and inconsistent data. The main goal of this project is to clean the raw data and extract useful business information from it.

---

## 📌 About The Project

For this project, I worked with a dirty cafe sales dataset and performed different data cleaning and analysis operations using the libraries of python.

I started with the raw dataset and checked its structure, missing values, duplicate records and data types.

After that, I cleaned the data and performed some basic sales analysis such as:

- Total revenue
- Total number of transactions
- Average transaction value
- Top-selling items
- Revenue generated by each item
- Payment method analysis
- Monthly sales
- Highest-value transaction

Finally, I exported the cleaned dataset into a CSV file and created an Excel report containing different analysis results.

---

## 🎯 Objectives

The main objectives of this project are:

1. Understand the structure of a real-world messy dataset.
2. Identify missing and incorrect data.
3. Remove duplicate records.
4. Clean inconsistent values.
5. Convert columns into appropriate data types.
6. Calculate revenue from quantity and price.
7. Perform basic sales analysis.
8. Generate useful business insights.
9. Export the cleaned data and analysis results.
