## ☕ 01. About The Project

Welcome to the **Dirty Cafe Sales Data Analysis** repository! This project tackles a real-world messy dataset filled with missing values, duplicate records, incorrect formatting, and structural anomalies. 

Using **Python** and **Pandas**, the primary objective is to clean, transform, and extract actionable financial insights from chaotic raw data.

> 💡 **Core Mission:** *Turning messy cafe records into brewed-to-perfection business intelligence.*

---

## 🎯 02. Project Objectives & Workflow

<details>
<summary><b>🔍 Click to expand core pipeline phases & goals</b></summary>

| Phase | Objective | Description |
| :--- | :--- | :--- |
| **1. Inspection** | **Structure Analysis** | Identify shape, data types, null counts, and dirty data patterns. |
| **2. Sanitization** | **Data Cleaning** | Handle missing rows, drop redundant duplicates, and fix typos. |
| **3. Transformation** | **Feature Engineering** | Cast columns into proper types and derive total revenue metrics. |
| **4. Analytics** | **Sales Metrics** | Calculate total revenues, transaction volumes, and average basket sizes. |
| **5. Insights** | **Business Intelligence** | Discover top-selling items, preferred payment modes, and monthly trends. |
| **6. Reporting** | **Automated Export** | Save cleaned CSV files and customized multi-sheet Excel reports. |

</details>
